# بازار | دستیار خرید هوشمند

پروژهٔ فروشگاه PHP با نمایش محصولات از دیتابیس، دستیار خرید، صفحهٔ جزئیات محصول و سبد خرید مبتنی بر نشست PHP.

## ساختار مخزن

- `app/`: منطق برنامه، کنترلرها، مدل‌ها، درگاه هوش مصنوعی و ابزارها
- `config/*.example.php`: نمونهٔ تنظیمات؛ فایل‌های واقعی و رمزها نباید وارد Git شوند
- `database/`: طرح دیتابیس، مهاجرت‌ها و داده‌های نمونه
- `docs/`: راهنمای استقرار و نگهداری
- `prompts/`: دستورالعمل فارسی دستیار
- `public/`: فقط فایل‌هایی که باید در وب قابل دسترسی باشند؛ شامل `_bootstrap.php` برای یافتن فایل bootstrap خصوصی

## استقرار روی سرور فعلی

سرور از `/var/www/html` به‌عنوان DocumentRoot استفاده می‌کند. برای همین سرور، محتویات `public/` در ریشهٔ `/var/www/html/` کپی می‌شوند و فایل‌های داخلی برنامه در مسیر خصوصی `/var/www/smart-shop-private/` نگهداری می‌شوند. راهنمای دقیق و ترتیب امن استقرار در [docs/deployment.md](docs/deployment.md) است.

**مهم:** فایل `index.html` قدیمی در ریشهٔ وب‌سایت می‌تواند پیش از `index.php` انتخاب شود. پیش از فعال‌سازی صفحهٔ اصلی PHP، از آن نسخهٔ پشتیبان تهیه و آن را از DocumentRoot خارج کنید. فایل‌های آزمایشی API نیز نباید در ریشهٔ عمومی قرار بگیرند.

## قابلیت‌ها و محدودیت‌ها

- محصولات از دیتابیس خوانده می‌شوند.
- سبد خرید فعلی در PHP session نگهداری می‌شود.
- پرداخت آنلاین و ثبت سفارش نهایی هنوز پیاده‌سازی نشده است.
- تنظیم نمونهٔ هوش مصنوعی روی حالت آزمایشی `mock` است تا زمانی که تنظیمات ارائه‌دهنده روی سرور به‌صورت امن تکمیل شوند.

## بررسی خودکار

GitHub Actions بررسی نحوی فایل‌های PHP را انجام می‌دهد. این بررسی به‌تنهایی جای آزمایش اتصال واقعی به دیتابیس، سرویس هوش مصنوعی و آزمون مرورگر را نمی‌گیرد.
