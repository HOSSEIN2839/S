# دیتابیس دستیار خرید هوشمند

این پوشه ساختار عمومی دیتابیس کاتالوگ محصولات را نگه می‌دارد. نمونه‌های ارسالی WooCommerce فقط برای شناخت شکل داده‌ها استفاده شده‌اند؛ دیتابیس به سه محصول نمونه محدود نیست.

## فایل‌ها

- `schema.sql`: ساخت دیتابیس `smart_shop` و جدول‌های آن؛ بدون واردکردن کاتالوگ واقعی.
- `sample_data.sql`: چند رکورد نمایشی اختیاری برای آزمایش ساختار.
- این ساختار برای MySQL 8 و نسخه‌های جدید MariaDB در نظر گرفته شده است.

## جدول‌ها

- `products`: اطلاعات پایه، توضیحات، قیمت‌ها، موجودی، لینک و داده‌های تکمیلی محصول.
- `brands`: برندها.
- `categories` و `product_categories`: دسته‌بندی‌ها و رابطه چندبه‌چند محصول/دسته‌بندی.
- `product_images`: یک یا چند تصویر برای هر محصول.
- `product_attributes`: مشخصات انعطاف‌پذیر مثل رنگ، جنس بند، اندازه و قابلیت‌ها.
- `product_tags` و `product_tag_map`: برچسب‌ها.

شناسه منبع در `source_product_id` حفظ می‌شود تا محصول با شناسه فروشگاه اصلی قابل تطبیق باشد. قیمت‌ها از نوع `DECIMAL` هستند. فیلدهای اختیاری در صورت نبود داده خالی می‌مانند و نباید از روی حدس پر شوند.

## نصب روی سرور

1. ابتدا از دیتابیس موجود نسخه پشتیبان بگیرید، اگر از قبل داده‌ای دارد.
2. فایل `schema.sql` را در محیطی که به MySQL دسترسی دارد اجرا کنید، مثلاً از طریق phpMyAdmin یا خط فرمان.
3. برای واردکردن رکوردهای آزمایشی، به‌صورت جداگانه `sample_data.sql` را اجرا کنید؛ این مرحله اختیاری است.
4. برای کاتالوگ واقعی باید فرایند واردسازی از API یا فایل اصلی محصولات اجرا شود. فایل نمونه به معنی واردشدن تمام محصولات نیست.

نمونه خط فرمان:

```bash
mysql -u shop_user -p < database/schema.sql
```

اگر دیتابیس `smart_shop` و کاربر `shop_user` از قبل ساخته شده‌اند، این فایل ساختار جدول‌ها را در همان دیتابیس ایجاد می‌کند. اجرای آن روی دیتابیس موجود، جدول‌های هم‌نام را حذف نمی‌کند و از `CREATE TABLE IF NOT EXISTS` استفاده می‌کند.

## نکته امنیتی

رمز دیتابیس و کلیدهای API را داخل GitHub قرار ندهید. اطلاعات اتصال باید در فایل تنظیمات خارج از پوشه عمومی وب و با دسترسی محدود نگهداری شوند.
