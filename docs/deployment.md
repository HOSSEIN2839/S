# راه‌اندازی برنامه فروشگاه

## ساختار و اجرا
- ریشه عمومی وب‌سرور باید به پوشه `public/` اشاره کند؛ پوشه‌های `app/`, `config/`, `database/`, `prompts/` و `logs/` نباید مستقیماً از وب قابل‌دسترسی باشند.
- روی سرور از نسخه‌های واقعی تنظیمات کپی بسازید: `config/app.example.php` به `config/app.php`، و همین‌طور برای `ai`، `database` و `secrets`.
- رمز دیتابیس و کلید API واقعی را فقط در فایل‌های تنظیمات سرور قرار دهید؛ این فایل‌ها را به Git اضافه نکنید.
- برای اجرای گفتگو، ابتدا `database/schema.sql` و سپس `database/migrations/001_conversation_tables.sql` را روی دیتابیس `smart_shop` اجرا کنید. مهاجرت را روی نسخه پشتیبان و محیط درست بررسی کنید؛ از اجرای کورکورانه روی دیتابیس تولید خودداری کنید.
- برای استفاده واقعی از مدل، در `config/ai.php` مقدار `mode` را روی `live` بگذارید و `base_url`، `chat_path`، `model` و کلید API را طبق ارائه‌دهنده تنظیم کنید. تنظیم نمونه به‌صورت پیش‌فرض روی `mock` است.

## قابلیت سبد خرید
سبد خرید فعلی در PHP session ذخیره می‌شود و پرداخت آنلاین/ثبت سفارش نهایی ندارد. برای فروش واقعی، مرحله بعد باید سفارش‌ها، کنترل موجودی در لحظه ثبت سفارش و درگاه پرداخت امن را اضافه کند.

## آزمون
GitHub Actions در هر push بررسی نحوی PHP و وجود مسیرهای اصلی را اجرا می‌کند. این بررسی جای آزمون اتصال واقعی به MySQL، ارائه‌دهنده هوش مصنوعی و مرورگر روی سرور را نمی‌گیرد.
